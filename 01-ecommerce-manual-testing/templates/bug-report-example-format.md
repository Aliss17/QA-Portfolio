# Example Bug Report Format (Illustrative Only)

This example demonstrates the structure of a report. It is **not a confirmed SauceDemo defect**.

- **Bug ID:** BUG-XXX
- **Title:** [Short description of observed behavior]
- **Module:** Cart
- **Environment:** [Your actual browser and OS]
- **Preconditions:** User is signed in and a product is in the cart.
- **Steps to reproduce:**
  1. Open the cart.
  2. Perform the action that appears to cause the issue.
  3. Observe the result.
- **Expected result:** [What the requirement or expected workflow says should happen]
- **Actual result:** [What you actually observed]
- **Severity:** [Choose based on impact]
- **Priority:** [Choose based on urgency]
- **Evidence:** [Path to your screenshot]

Replace every bracketed field with verified observations before publishing a real bug report.

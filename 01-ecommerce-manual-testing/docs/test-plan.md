# Test Plan — SauceDemo E-commerce Website

## 1. Purpose
Define the approach for testing the main shopping workflow in SauceDemo.

## 2. Objectives
- Verify that users can sign in and sign out.
- Verify product information and sorting.
- Verify cart operations.
- Verify checkout validation and order completion.
- Identify, reproduce, and document defects.

## 3. Test approach
Use manual black-box testing. Compare actual application behavior with the expected results described in each test case. Include positive and negative scenarios.

## 4. Entry criteria
- Website is accessible.
- A supported browser is available.
- Demo test credentials are available from the application.

## 5. Exit criteria
- All in-scope test cases have an execution status.
- Failed tests have reproducible evidence and defect reports where appropriate.
- Test summary is completed with actual counts.

## 6. Risks and assumptions
- The demo website may change without notice.
- Demo accounts may behave differently; record the account used.
- Network or service interruptions can affect results.
- Do not assume a suspected issue is a defect until it is reproduced and checked against expected behavior.

## 7. Defect fields
Use a unique ID, title, environment, preconditions, steps, expected result, actual result, severity, priority, status, and evidence.

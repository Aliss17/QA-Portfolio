# Project 1: E-commerce Website — Manual Testing

**Application:** SauceDemo — https://www.saucedemo.com/  
**Testing type:** Functional, UI, positive, negative, and regression-oriented checks  
**Level:** Beginner to intermediate

## Objective

Validate key customer journeys in a sample online store: authentication, product browsing, sorting, cart management, checkout, and order completion.

## Scope

### In scope
- Login and logout
- Product inventory display
- Product sorting
- Add/remove items from cart
- Cart contents and navigation
- Checkout form validation
- Order overview and completion

### Out of scope
- Real payment processing
- Security penetration testing
- Load/performance testing
- Real-world order fulfilment

## How to execute

1. Open the website and verify it loads.
2. Use the demo credentials currently shown by SauceDemo.
3. Execute test cases in `docs/test-cases.csv`.
4. Enter the actual result and choose Pass, Fail, Blocked, or Not Run.
5. Attach screenshots for failed tests in `evidence/`.
6. For every reproducible failure, create a separate report using `templates/bug-report-template.md`.
7. Complete `docs/test-execution-summary-template.md`.

## Test data

Use only the public demo test data provided by SauceDemo. Do not use personal credentials or payment information.

## Deliverables

- Test cases and execution results
- Reproducible defect reports (if any)
- Evidence screenshots
